## Newly found defects (none blocking)

**1. Minor, confirmed — stale copy-failure message in verification doc.**
`site/docs/browser-verification.md:30` records `Copy failed. Select code to copy.`, but `site/src/site.js:62-63` now emits `Copy failed. Select the code and copy it manually, or try again.` (verified live in this run's browser check). The message was changed in this UI turn without refreshing the recorded evidence; the same report's "18 results" for `usize` is now 19. User-visible effect: none in the product; the verification record misdescribes shipped behavior. Existing tests miss it because no test pins user-facing strings and nothing cross-checks evidence docs against code. Fix: refresh those two lines in `browser-verification.md` (or re-run the interaction probe and update the evidence JSON).

**2. Minor, confirmed — two sources of truth for 404.html.**
`public/404.html` (tracked) and the template written by `scripts/build.ts:102-104` differ by a leading newline; the build's copy always wins in `dist/`. No user-visible effect today, but future edits to one copy silently diverge from the served page. Tests miss it because nothing compares them. Fix: delete `public/404.html` or render it from the same template constant.

**3. Minor, plausible — search excerpt anchors on the first term only.**
`src/site.js:213` offsets the 180-char excerpt at `terms[0]`. If the first term matched only the title or a feature ID and not the section body, the excerpt shows the section start with no highlighted hit (highlight falls back to plain text since no term occurs in the window). Ranking still surfaces the section; this is a cosmetic loss, not a wrong result. Not browser-reproduced (inferred from code). Fix: pick the first term present in `plain` for the offset and use it for the highlight fallback.

**4. Nit, confirmed — duplicated/lated CSS overrides.**
`.page-outline a[aria-current]` and `.mobile-outline a[aria-current]` repeat identical rules (`src/tailwind.css:458,652`), and lines 879-894 append override blocks after the media queries. Maintenance-only. Fix: merge selectors.

**5. Nit, confirmed — CI passes an ignored flag.**
`deploy-docs.yml:46` and `ci.yml:114` run `bun run lint -- --max-warnings=0`; `scripts/lint.ts` accepts no arguments, so the flag is silently ignored. Misleading to readers, no behavior effect. Fix: drop the flag or add argument rejection.
