ok = True
worst = 0
for a in range(-4096, 4097):
    ba = abs(a).bit_length()

        bb = abs(b).bit_length()
        for op, r in (("&", a & b), ("|", a | b), ("^", a ^ b)):

**Corrected rules**

1. **Rational add/sub carry — one rule, ≤ C4 everywhere.** Preflight requires the numerator-sum bound `max(cross-product bounds) + 1 ≤ C4`; gcd inputs, per-operation temporaries and the §5.1 memory summary now all say ≤ C4 bits (the stale "C4+1" wording described an unguarded carry the preflight never permits). Peak recount: 4×C3 + 4×C4 bits ≈ 192 KiB logical (was miscounted ≈ 160 KiB); gcd charges were already C4-based and are unchanged (2 × (C4/64)²).
2. **Bit length defined; signed bitwise/complement preflight added.** Bit length = magnitude bit length (`int.bit_length()` semantics); negatives are exact with two's-complement sign-extension for bitwise ops. Bitwise `& | ^` now preflights `max(ba, bb) + 1 ≤ C3` (old "result cannot exceed the wider operand" was false: −1 ^ 1 = −2), and a new complement row (`~`, `UnaryOp.BIT_NOT`) preflights `ba + 1 ≤ C3`. Verified by a bounded small-range scratch-Python check (a ∈ [−4096, 4096], b ∈ [−256, 256]; max growth exactly 1 bit); no compiler run, no exhaustion.
3. **Rounding no longer a blanket exemption; C5 scope widened.** The §4 rounding row now requires every internal shift, division, multiplication, comparison and scan to pass its own preflight and §5 charge (scans charge the linear row; shifts/divisions charge theirs). C5 is charged per *evaluated constant initializer* — `::` bindings, constants in ordinary variable initializers, and fitting/rounding contexts. Diagnostic and emission conversions stay outside the initializer charge and bounded by §7/C9/C11.
4. **"Hand-written constants ≤ ~390 bits" removed.** Only the explicitly bounded ≤ 20-char, |exponent| ≤ 99 class carries that size; the general margin statement defers to the C1+C2 worst case (~13,930 bits, ~9.4x).

Correction log extended with items 11–14 documenting this pass; remaining "C4+1" strings are deliberate negations. The policy remains proposed, not implemented, not qualified.
