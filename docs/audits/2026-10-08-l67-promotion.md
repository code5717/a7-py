# L67 benchmark promotion

The three workloads selected by L67 are copied unchanged from
`tmp/b-benchspec/` into `bench/`: `mem_shared`, `mem_returned` and `mem_cleanup`.
The benchmark harness and native build corpus now include all three.
Cache, copy, text and cyclic workloads remain outside this promotion.

Before promotion, each workload passed Debug, ReleaseSafe and ReleaseFast
against frozen compiler source `de578138`. All nine native runs exited 0,
matched exact stdout and produced empty stderr:

| Workload | Expected stdout |
| --- | --- |
| `mem_shared` | `result: 49999995000000\n` |
| `mem_returned` | `result: 50000005000000\n` |
| `mem_cleanup` | `result: 9999900 100\n` |

The first two oracles are the sums of integers from 0 through 9,999,999 and
1 through 10,000,000. The third counts 9,999,900 explicit-deletion paths and
100 paths that omit deletion. It does not measure physical frees or retained
bytes. Successful optimized execution does not prove that the optimizer retained
all intended allocation work.

The [native record](../../tmp/v1-completion-2026-10-07/l67-native-correctness/REPORT.md)
preserves 29 commands, 58 streams and 18 generated artifacts. All 1,664 frozen
source hashes and modes stayed unchanged. Original workload hashes match the
promoted copies. Runs used CPUs 0–3, pinned Zig 0.16.0, private outputs and
inherited HOME. No performance measurement or memory-mechanism selection is
claimed.

`bench/pins/cx89.json` remains unchanged. The real `bench_perf.py --gate` command
exits 1 before building because the three new entries have no timing/hash pin.
This is the required incomplete-pin behavior. L56 still requires an idle host
before re-pinning. Host-relative timing pins cannot establish L38's per-workload
C-relative runtime and peak-live-memory limits.

Post-promotion checks passed 34 tests in `test_feature_pins.py` and
`test_bench_missing_pin.py`. They include native builds of all 13 benchmark
programs in Debug and ReleaseFast, corpus membership and the controlled pin
contract tests. Full pytest and the release wrapper were not rerun.

Independent built-in review confirmed exact workload copies, the three harness
and corpus entries, unchanged host pin and stated evidence limits. External GLM
review remains unavailable; the built-in review does not replace it. Parent
verification rehashed all 1,664 frozen source files, 58 streams and 18 artifacts.
The [promotion verification](../../tmp/v1-completion-2026-10-07/l67-promotion/verification.json)
records test results, source hashes, the expected gate exit 1 and remaining limits.
